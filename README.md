# Jogo da Forca em C

Implementação do clássico **Jogo da Forca** em linguagem C, executado diretamente pelo terminal e utilizando apenas a biblioteca padrão da linguagem.

O jogador deve descobrir a palavra oculta informando caracteres individualmente, respeitando um limite de 10 erros.

## Funcionalidades

- Entrada de caracteres pelo terminal
- Conversão automática das letras para minúsculas
- Validação de caracteres repetidos
- Verificação de acertos e erros
- Exibição da palavra em tempo real
- Controle das tentativas realizadas
- Identificação automática da palavra descoberta
- Limite de 10 erros
- Possibilidade de iniciar uma nova rodada

## Conceitos de C utilizados

O projeto explora diferentes conceitos fundamentais da linguagem:

- Funções e modularização
- Vetores e strings
- Ponteiros e passagem por referência
- Estruturas de repetição e condicionais
- Manipulação de caracteres
- Valores booleanos com `stdbool.h`
- Manipulação de strings
- Validação de entrada
- Controle do fluxo de execução com `goto`
